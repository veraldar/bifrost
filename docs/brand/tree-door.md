# The tree door — hold-to-start wording options

*BRAND session, 2026-10-03, for comms (user request via product session).
Canon: THE TREE IS THE DOOR — veraldar.org's tree is hold-to-start vocal
onboarding handing a personalized install; the PWA first-run is tree-centered
main creation. Wording law: the tree states facts; it never begs, pleases,
or emotes (loyalty clause, brand.md §3). The human acts; the tree answers.*

## Options

| # | Wording | Where it lives | Note |
|---|---|---|---|
| 1 | `hold the tree to begin` | veraldar.org door (cold visitor) | plainest true sentence — **recommended default** |
| 2 | `hold. say what you want to build.` | door, personalized-install handoff | speaks the outcome, not the mechanism |
| 3 | `hold to be heard` | in-app listening state | existing canon line since the first wireframe — keep, don't duplicate elsewhere |
| 4 | `your main grows here` | PWA first-run, under the tree | states the fact of main creation; pairs with 1 or 2 |
| 5 | `hold the tree. name it.` | first-run main naming moment | shortest ritual; door + creation in one |

## State pairs (the door's honesty)

- held: `heard` — amber, glow; nothing more
- released early: `released — nothing sent` (neutral, no guilt, no "are you sure")
- done: `planted` (main created) / `sent` (install handed off)

## Rules

- One hold phrase per surface. The door never stacks imperatives.
- Never: "tap me", "come in", "don't be shy", "I'm listening" (the tree has
  no self), please/thanks, exclamation marks.
- Release copy is neutral — the door doesn't miss you if you let go.

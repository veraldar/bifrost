Bifrost is a private, self-hosted, voice-first remote for the coding agent you already run. Push-to-talk or hands-free from the couch; the code changes on your box. Local speech models, nothing public, no subscription — the big products sell you the model, bifrost gives you the remote.

three steps, zero dashboards

No account, no cloud console, no telemetry toggle to hunt for. If you can run git and docker, you can run bifrost.

STEP 1

Paste the link

Give any coding agent the skill URL and the words set it up. It fetches the skill, clones the repo, checks prerequisites, mints every secret.

STEP 2

Your box starts serving

LiveKit + voice agent + opencode + the PWA come up as systemd units and a docker compose. Reboots self-heal. Everything stays on your tailnet.

STEP 3

Talk to it

Open the PWA on your phone. Hold to talk, or go hands-free. Speech is transcribed locally, your agent works, and it speaks the result back.

the demo is your voice

Push-to-talk commits the turn the moment you lift. Hands-free listens for pauses and takes turns on its own — keyboard mode releases the OS mic instantly, so the indicator never lies to you.

Voice lands in the same transcript as text: room name = session slug, so what you said on the couch is what the agent sees at the desk. Attach a photo or a file from the phone mid-conversation.

30-second demo video lands with the v0.4.0 release.

runs here, not "in the cloud"

One Linux box is the whole server. Speech runs on local models — an MLX box is a quality upgrade, a CPU fallback ships in the compose. Nothing needs a public port.

what you need / what it won't do (yet)

Stated up front, because you'd find out anyway.

■ what you need

  • One Linux box — Omarchy, Arch, Debian, anything with docker + Node ≥ 22. No Mac required.
  • Your LLM key — opencode auth login is the one manual step. Or point opencode at a local model; your call.
  • Docker — for the voice stack (LiveKit + CPU speech fallback).
  • Tailscale — recommended. Default topology is tailnet-only; zero public exposure.

■ honest limits

  • Enthusiast release. v0.4.0 assumes terminal comfort; one-button consumer onboarding is v1.0.
  • Hands-free is fresh off a fix. Push-to-talk is the battle-tested mode; the full hands-free pass gates this release.
  • One harness today. opencode. Claude Code / Copilot connectors are specced, not shipped.
  • The coding model is not ours. Speech is local; the LLM is whatever opencode is configured with.
  • Linux server only. Your phone is the client (PWA); the box runs Linux.
Built for people who live in a terminal. If git clone and docker compose up are things you do without looking them up, bifrost is ready for you today. If not — star it, come back at v1.0.

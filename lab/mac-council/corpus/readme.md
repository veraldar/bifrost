# KVStore (kvx) — project overview

kvx is a small embedded key-value store used by the taskrunner demo project.
Current release: **v2.3.1**. Default cache capacity is **512 entries**.
The CLI binary is `kvxctl`. Configuration lives in `conf/settings.ini`.

See also: docs/history.md for the changelog, docs/limits.md for capacity rules,
docs/api.md for endpoint shapes, ops/runbook.md for incident handling.

# bifrost v0.7.0 — its own tree

The brain is now **yggdrasil**, the root that runs on your own computer (opencode-compatible,
`lab/yggdrasil`). Same phone app, same private line (tailscale), same LiveKit voice. One change
for this version, as the ladder says (docs/STABLE.md).

**What you get**
- The root as the brain: sessions, tool use, a declared run state (working / blocked / idle),
  cut-off replies never stored as complete, a restart closes open runs as `blocked/interrupted`.
- The root knows where it is: the `AGENTS.md` chain rides every run (opencode parity).
- The front page: tap the roots = MAIN, hold the roots = talk to MAIN without leaving.
- Onboarding from veraldar.org's door: pre-recorded greeting (~100 ms), any coding plan.
- Voice: the 10-06 outage fixes (no dropped dispatches, ordered duplicate-agent yield,
  split-brain + speech-server watchdogs) and the TTS generation lock (no stutter).
- Rollback is one command: `scripts/promote.sh --rollback` (v0.6.1 stays on disk, its brain running
  for the rollback week). The root's store is snapshotted and its restore proven.

**Served artifact.** The build you run is the one that was consent-checked: tag `v0.7.0-rc2`
(commit `c4b1908`, build `2-tWDJZQP2Pr6PIGTVDsF`). The app shows `0.7.0-rc2`, deliberately:
it is that frozen build, not a rebuild. `v0.7.0` tags the same commit. (The 10-07 fleet-sync
snapshot that carried the `v0.7.0` tag before is kept as `v0.7.0-fleetsync`; it never had a release.)

**Known issues (fixed in v0.7.1, in this order)**
- Voice turns can arrive twice or run on noise (exactly-once on the voice path; the language pin).
  Related: a voice agent sent into a room whose page left before joining stays there until the
  room's ~5 min empty timeout; the next press then waits up to 20 s on that agent. Use one origin
  (:443 or :8443) at a time for MAIN's voice.
- "Bifrost" said at the very press can lose its first syllable (onset; needs capture from the press).
- A second message sent while MAIN works can abort the first (send-while-working).
- The voice agent finds the session by name, not id (a renamed namesake can take voice turns).
- No model shown per reply; the "what runs" chips are not in this version.
- Re-dispatch of the agent into an agent-less room, the black page for directly opened text
  artifacts, and the declared `BIFROST_AUTH` guard are on v0.6.1 but not yet on this line.

**Named SKIPs (simulation can't reach them)**: the phone's mic privacy toggle, One UI battery
rules on notifications, room acoustics beyond the replay test, screen-off voice (v0.8).
A stranger install of the root is not proven in this version: the installer ships with v0.8.

**Next:** v0.8 = the bridge + device tokens + the Android app as the first client.

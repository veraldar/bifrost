# Coordination

MAIN runs the mission lanes; the **coordinator profile** (`config/yggdrasil-profiles.json`, the `coordinator` entry) is its tool fence: it manages sessions over the root's own API (:4100), reads to answer, never writes. **lane-watcher** (`scripts/lane-watcher.sh` + `.service`) is MAIN's initiator: it polls `/tmp/sub-status.tsv` — mission runners append one line per lane landing — and when the tail changes it POSTs that line into MAIN's session so MAIN wakes and reviews it. Ports: brain :4100, PWA :8090/:8443. To enable on a fresh box: install the brain, then `mkdir -p ~/.config/bifrost && cp config/yggdrasil-profiles.json ~/.config/bifrost/ && cp scripts/lane-watcher.service ~/.config/systemd/user/ && systemctl --user daemon-reload && systemctl --user enable --now lane-watcher` — done; `journalctl --user -u lane-watcher -f` shows the wake lines.
